# GermanApp Online (v0.5)

A Neubrutalism-inspired web application for German language learning, built with React 18, Tailwind CSS, and Google Identity Services.

## 📄 Release Notes — v0.5
* Modularized CSS into `css/main.css`
* Separated React application components and auth logic into `js/`
* Connected relative cross-navigation between all portal views
